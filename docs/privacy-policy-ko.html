2. 개발자가 수집하는 개인정보

없습니다. 계정 시스템, 서버, 자체 분석 도구를 운영하지 않습니다. 사용자가 선택하거나 설정한 내용은 개발자에게 전송되지 않습니다.

3. 기기 안에 저장되는 데이터

앱은 다음 항목을 Android 자체 저장공간에 보관합니다. 이 데이터는 기기 밖으로 전송되지 않습니다.

항목목적
효과음·애니메이션 설정 (선택한 프리셋, 볼륨, 진동, 테마)설정 유지
잠금을 해제한 프리미엄 항목 및 광고 시청 진행도해제 상태를 기기에 기억
사용자가 선택한 오디오·영상 파일의 이름과 로컬 경로선택한 파일 재생
권한 상태 (알림, 다른 앱 위에 표시)안내 표시 판단

앱 데이터 삭제 또는 앱 삭제 시 위 데이터는 영구히 사라집니다. 오디오·영상 접근은 사용자가 직접 시스템 파일 선택기로 파일을 고를 때만 요청되며, 선택한 파일만 읽습니다.

4. 광고

앱은 Google AdMob(Google Mobile Ads SDK)을 통해 광고를 표시합니다. 광고 제공과 과금은 Google이 담당합니다.

광고 게재에 사용되는 데이터

  • 광고 고유 식별자(com.google.android.gms.permission.AD_ID) — 기기별 광고 식별용 재설정 가능한 값
  • 기기·광고 상호작용 정보 — 기기 모델, OS 버전, 앱 버전, IP 주소, IP 기반 대략적 지역, 광고 시청·클릭 여부

Google은 Google 개인정보처리방침 및 Google 광고 정책에 따라 이 데이터를 처리합니다. 개발자는 Google로부터 이용자의 이름·이메일·전화번호 등 신원을 받을 수 없으며, 받지 않습니다.

사용자 선택

  • 광고 고유 식별자 초기화/삭제 — Android 설정 > 개인정보 보호 > 광고, 또는 myadid.google.com
  • 광고 개인화 끄기 — Android 설정 > 개인정보 보호 > 광고
  • 앱 내 광고 없는 시간 — 보상형 광고를 시청하면 원하는 시간 동안 배너가 숨겨집니다. 거부해도 어떤 기능도 제한되지 않습니다.

어떤 권한을 거부하더라도 앱의 핵심 기능은 제한되지 않습니다.

6. 아동 및 청소년

ChargeSound는 만 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다. 앱이 광고를 제공하므로 아동용 앱이 아닙니다. 아동이 사용했다고 판단되는 경우 문의해 주시면 확인하겠습니다.

7. 보안

앱의 모든 데이터는 운영체제가 다른 앱과 격리하는 Android 자체 저장공간에 보관됩니다. 개발자는 사용자 데이터를 전송받지 않으므로 보관·보호할 데이터가 없습니다. 광고 데이터는 Google이 암호화된 연결로 전송합니다.

8. 데이터 삭제

개발자가 보유하는 데이터가 없으므로 삭제 요청을 처리할 대상도 없습니다. 사용자가 언제든지 직접 삭제할 수 있습니다.

  • Android 설정 > 앱 > ChargeSound > 저장소 > 데이터 삭제, 또는
  • 앱 삭제(삭제)

광고 고유 식별자 삭제 방법은 4항을 참고하세요.

9. 사용자 권리 (GDPR / UK GDPR)

EEA·영국 등 유사한 법역에 거주하는 경우 개인정보에 대한 열람·정정·삭제·이용정지·처리반대 권리와 мест 감독기관에 대한 불만 제기 권리가 있습니다.

개발자가 서버를 운영하지 않고 개인정보를 보유하지 않으므로 열람·삭제 요청을 처리할 대상이 없습니다. Google이 귀하의 광고 제공자로서 보유한 데이터는 4항의 링크 또는 Google 개인정보처리방침을 이용하세요.
